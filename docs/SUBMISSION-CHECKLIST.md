# Week 1 submission checklist

- New project and repository created inside the October 5–11 entry window.
- Demonstrate a real open-weight model call. Keep sample mode visibly identified.
- Compare two small open-weight models on the same cases. Measure schema/catalog validity, equipment/time compliance, latency and provider cost. Report failures.
- Verify paid Backboard and ElevenLabs with server keys before listing them as demonstrated integrations.
- Complete one real outdoor session: record time preparing, time outside, number of screen checks, and one observation or weakness. This cannot be replaced by browser testing.
- Demonstrate saving, offline reload and downloaded audio playback on a phone.
- Record a 60–90 second demo and include a code repository link. A video demo satisfies the rules even without a deployed URL.
- Use the official DEV template: What I Built, Demo, Code, How I Built It, Why Does Open Innovation Matter?, optional My Agent Session, and genuine Prize Categories.
- Use `devchallenge` and `hf26challenge` tags; use English when competing for prizes.
- Explain model portability, local versus hosted inference, what stays on the device, and the limitation that offline phone use covers saved packs rather than new inference.
- Publish one submission, not a separate post for each partner category.
- Submit by October 11 at 8 PM IST as the personal target. The official deadline is October 12 at 12:29 PM IST.
- Identify any post-deadline commits in the README.

Sources: https://dev.to/challenges/hacktoberfest-week1-2026-10-05 and https://dev.to/page/hacktoberfest-week1-2026-10-05-contest-rules
